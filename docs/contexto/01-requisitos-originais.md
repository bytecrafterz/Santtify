## Descrição original (verbatim)

Procuro um desenvolvedor experiente para criar um Progressive Web App (PWA) robusto para o projeto educacional infantil "Jesus Alfabeto Saudável". Este PWA será a primeira aplicação de uma tecnologia própria, o "Produto Vivo", que visa transformar qualquer site ou aplicativo em uma mini rede social.

O projeto consiste em 26 letras, cada uma associada a um QR Code exclusivo. Ao escanear o QR Code, o usuário será direcionado a uma página dedicada que incluirá:

* Música
* Áudio
* Letra da música
* Conteúdo educativo relevante

Além disso, o PWA deverá integrar uma área social simples, permitindo aos usuários:

* Curtir conteúdos
* Deixar comentários
* Compartilhar informações
* Visualizar o número de interações

Cada usuário terá um perfil personalizado, exibindo:

* "My Posts" (Minhas Publicações)
* "My Record" (Meu Registro)
* "Meus Lançamentos"

Um dashboard administrativo será essencial para monitorar o desempenho e a interação dos usuários, apresentando métricas como:

* Número de visitantes
* Total de visualizações
* Tempo médio de permanência
* Conteúdos mais acessados
* Estatísticas detalhadas de interação

Todo o conteúdo necessário, incluindo textos, músicas e áudios, será fornecido por mim. Busco um profissional organizado, com comprovada experiência em desenvolvimento de PWA, proficiência em React/Next.js, Node.js ou NestJS, conhecimento em banco de dados, implementação de sistemas de autenticação e integração de funcionalidades de QR Code. O objetivo é estabelecer uma parceria de longo prazo para o desenvolvimento e evolução contínua deste projeto e da tecnologia "Produto Vivo".
